# 🎃 Goodnight Family — How to Choose a Pumpkin

**[Open the family organizer](https://jacobmgoodnight.github.io/pumpkin-family-organizer/)**

## For carving night

1. A parent signs into the family account on each phone/computer. Children **never** need their own email or password.
2. Choose your name: **Jacob, Shelby, Charlotte or Violet**.
3. Search for a character or subject. The search suggests designs as you type. Browse all templates, or choose curated Zombie Pumpkins.
4. Tap **♡** on pictures you like. Go to **♥ My favorites** to see your shortlist.
5. Select **Compare** on two or three favorites if you want a side-by-side view.
6. Select **Choose this pumpkin** for your final design. You can keep multiple final selections; none are removed automatically.
7. Open **Family lineup** to see everyone's chosen designs and use **Print lineup** for a paper summary.

## Find the printable pattern

- **Built-in Zombie Pumpkins / Additional Templates:** Select **Find original**. The website tells you the local filename. On the computer with the licensed pattern collection, set the local library root once, copy the path and open it through Finder (macOS) or File Explorer (Windows). The licensed PDFs are **not** on GitHub Pages or automatically accessible from phones.
- **Family imports:** Select **Open printable**. This accesses an authorized PDF/image in your family's private cloud storage while signed in. The link expires and may need the gallery reopened after a long session.
- **Preview only:** You can still favorite the design, but there is no printable original available from that card.
- **Web ideas:** Save a link for inspiration. A Google search preview alone is *not* an imported pattern or a guarantee of a printable original.

## Find more designs

After searching your own library, choose **Find more online** to search Google Images. The additional cards appear inside the app. **Minimize** or **Close** the online panel to get back to your library. Searches made in Google Images count toward the shared search-provider allowance; browsing built-in patterns does not.

To add an authorized online design, select **Import image**. The app will attempt to retrieve the original image, if permitted by its website. Confirm you have permission, then use **Upload and add pattern**. Some sites block downloads: in that case open the source, save a printable image/PDF yourself, and select the file in the import form. For an authorized PDF, the app attempts to make its first-page gallery preview automatically.

For personal photos, publisher-supplied PDFs or other owned files, use **Import pattern**. Manage imports under **Library tools** → **Manage imports**, including editing titles and thumbnails.

## If something looks wrong

- **Missing photos:** Check that you're signed into the same parent account; refresh the page. All 2,053 original thumbnails have already been uploaded to private storage.
- **Syncing / offline message:** Your recent selection changes may still be saved on this device and pending upload. Reconnect to the internet and open the app again. Keep a backup before clearing browser storage.
- **Wrong person selected:** Choose the correct profile *before* favoriting or choosing a design.
- **Need a backup:** Use the JSON export in Settings. Restoring while signed in can change cloud selections on other family devices.
- **Can't print a built-in design on a phone:** That phone cannot access the PDFs on another computer. Use the original-file locator on the computer holding the purchased/authorized collection.

This app is a private family planner. Honor the creator's or publisher's rights before storing or sharing designs.


## Sign in without a password

Use the same **existing parent email address** used for this family organizer. **Send email sign-in link** does not need a password. If Supabase refuses OTP with “Signups not allowed for OTP,” check that the address exactly matches the registered parent account in Supabase Auth → Users; this is the common cause when new signups are blocked. the app does not create new accounts. You can also select **Set up / reset password** to request a password-recovery email. If an existing device is still signed in, the parent can set a password under **Family account settings** without needing another email. Email sending is rate-limited.

## Import a Google image from your phone

Select **Import image** on a Google Images card. If the original can be fetched, you'll see **Full-size original staged**; it still hasn't been uploaded. Confirm permission and select **Upload and add pattern**. If the host blocks the fetch, open the source, save an authorized printable image/PDF to Photos or Files, then choose **Choose file from phone or computer** in the same import form. The little Google Images thumbnail is not automatically a usable printable.


## Invite each person with their own private link

Parent: Sign in, expand **Family account settings → Share private family links**, select the expiration, then choose **Create private link** next to the person. Use **Share…** to send it by Messages/AirDrop or **Copy link** and paste into a trusted chat. No separate child email is required.

Recipient: Tap your personal link. You will see your own favorite and final-pick controls. You cannot change another person's picks or see the parent's settings. The link works until it expires or the parent revokes it.

Privacy: Anyone who receives the link can act as that person, so do not post it publicly. Parent can revoke it or generate a replacement; old links stop working.

## Faster home-screen navigation

The main search is now the first control on the page, with family profiles immediately beneath it. Type a few letters to see suggestions; choose your name so favorites and final picks go to your profile. The **More filters** button reveals collection, theme and difficulty filters when needed; tapping it again hides them. Use the four tabs to browse all, favorites, final picks or the family lineup.

**Who is the organizer?** It's whoever is signed into the existing adult Supabase parent account—the email displayed beside **Organizer** at the top. Choosing Jacob, Shelby, Charlotte or Violet does **not** make that person an administrator. The **Share links** shortcut opens the invite manager. If a person loses their link or you want a new one, tap **Replace link** for that person and copy/share the newly generated URL. The old link is immediately invalidated.


### Browsing from a phone

The opening order is now **choose your person → search → Browse / Favorites / Picks / Lineup**. Select the correct person first, then type in the search box; matching suggestions appear as you type. Tap **More filters** if you want to narrow to Zombie Pumpkins, Additional Templates, themes or difficulty; tap it again to hide them. The smaller **Import**, **Online designs**, and **Tools** actions are beneath the navigation tabs. On narrow screens, **Best match**, **Surprise**, and **Clear** sit together in one row, leaving more room for the pattern cards. The compact organizer strip still has **Links** for creating or replacing family invitations.


### Guest links now have the full selection experience

Using your personal invitation, tap any pumpkin image to enlarge it. Save favorites and select Final Picks for **your own profile**. Add 2–3 designs to Compare to see them side by side. Use **Whose designs are you viewing?** to check another family member's favorites and picks, or select **Family lineup** to browse everyone's choices. You may look but not edit other family members' lists.

Tap **Find more online** to search Google Images inside the guest page; results appear as cards. Open the source to find an authorized printable or use **Share idea** to send the link to the organizer. This does not automatically import a PDF. Online searches share the family API allowance; viewing the 2,053 built-in patterns doesn't use search credits.

On a phone, the organizer's top area is now a **single compact status strip** rather than a large account block. Tap **Links** to manage invitations or expand **Account settings** for the parent email, password and sign-out controls. The larger desktop organizer layout remains as before.


## Shared online ideas from a private participant link (October 30, 2026)
Invited family members can preview Google Images results, save a source link to the family's **Saved online ideas** collection, and favorite or compare that idea without an individual email account. Saved source links are visible after reload. They are **not** print-ready files: the organizer must import a permitted PDF/image for permanent printing. Built-in original PDFs stay on the organizer's computer. The family lineup is shown above guest catalog search, can be collapsed, and lets each person see the other family members' selections. Participant permissions allow editing only their own favorites/picks.


### Private invitation gallery quick navigation
Your private link opens with **family picks collapsed**, so you can start browsing. Tap **My favorites** or **My picks** to return to your own saved selections with one tap; the buttons show your current counts. **All designs** brings back the full gallery, and **Show family picks** expands the household lineup when you want to compare everyone's choices. These shortcuts never let you edit another person's favorites. Smart Search typing suggestions work here too, without calling Google or using search credits. For external Google Images results, open **Find more online** further down the page.
